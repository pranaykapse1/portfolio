## About the site

The portfolio presents selected CAD automation and mechanical design work, including pressure vessel systems, an evaporation plant configurator, engineering drawings, experience, and contact details. The project gallery uses CAD models, configurator views, and drawings from Pranay’s work.

The site is built with plain HTML, CSS, and JavaScript. It has no build step or package dependencies. Google Fonts load when the visitor has an internet connection; system sans-serif fonts are used as a fallback.

## Preview locally

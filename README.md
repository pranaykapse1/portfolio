# Pranay Kapse — Portfolio

A responsive, single-page portfolio site for GitHub Pages. It uses plain HTML, CSS, and JavaScript; there is no build step or dependency install.

## Preview locally

Open `index.html` in a browser. The Google Fonts link needs an internet connection; the page falls back to system sans-serif fonts when offline.

## Publish with GitHub Pages

1. Create a GitHub repository. For a personal site, name it `YOUR-USERNAME.github.io`.
2. Add the files in this folder (`index.html`, `styles.css`, `script.js`) to the repository root and commit them.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will show the published URL in the Pages settings when deployment finishes.

For a regular repository instead of a personal site, GitHub Pages publishes at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Before publishing

- Confirm the role, current employer, dates, and descriptions are accurate and safe to share publicly.
- Add links to live project demos, repositories, or non-confidential screenshots if you have them. The project diagrams here are illustrative, not screenshots of production work.
- The resume includes a phone number. It is intentionally not displayed on this public-facing page; email and LinkedIn are provided as contact routes.
- No date of birth, marital status, gender, or resume download is included.
- Check the LinkedIn URL and email address in `index.html` before publishing.

The site is designed to work on mobile, tablet, and desktop, and uses semantic sections and a keyboard-accessible navigation menu.
